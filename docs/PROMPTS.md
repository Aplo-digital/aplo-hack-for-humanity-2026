# Prompts to copy and paste

Paste these into your AI assistant one at a time. Wait for each one to finish and check the
result before the next. Change the words in [square brackets].

## 1. Get set up

> Read AGENTS.md, then set up this project on my laptop so I can run it. Explain each step
> simply.

> Run hello_gemma.py and tell me if Gemma answered.

## 2. Pick an idea

> Read docs/HACKATHON.md and data/README.md. We are interested in [Health / Education /
> Sustainability]. Suggest three app ideas that would help a real person in South Australia,
> using the ★ datasets. For each, say who it helps, which data it uses and what Gemma would do.

> Open [dataset name, for example S1] and show me what is in it in plain English: what one
> row means, the main columns and a few example rows.

## 3. Build the first version

> Build the first version of our app in app.py with Streamlit. It should [describe what a person
> does, for example: type a postcode and see how many homes have solar compared with the SA
> average]. Use [dataset]. Keep it simple, run it, and tell me how to open it in my browser.

> Add Gemma: when someone [picks a postcode], Gemma explains the numbers in two or three plain
> sentences, using only those numbers. Follow the Gemma rules in AGENTS.md.

## 4. Make it better

> Add a [chart / map / table] showing [what].

> Join [dataset A] with [dataset B] on [postcode / SA2 / LGA] so we can compare [what].

> Make the page easier to understand for someone who has never seen it. Check the wording,
> labels and order.

> Something is wrong: [describe what you see, or paste the error]. Find the cause and fix it.

## 5. Share with the team

> Pull the latest changes from GitHub, then commit my work with a clear message and push it.

## 6. Get ready to submit

> Go through docs/SUBMISSION-CHECKLIST.md with me. Fix what you can and tell me what is left.

> Rewrite README.md using docs/README-template.md for our project. Add the credit line from
> data/README.md for every dataset the app uses.

> Write a 3-minute demo script: the problem, who it helps, a live walk-through, and what Gemma
> adds.
