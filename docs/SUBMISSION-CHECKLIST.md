# Before the demo

Tick these off about an hour before demos. Your AI assistant can check most of them: paste
"Go through docs/SUBMISSION-CHECKLIST.md with me".

## The app

- [ ] `npm install && npm run dev` starts with no errors on a fresh pull
- [ ] Gemma answers, and the app shows a friendly message if it can't
- [ ] Someone who hasn't seen the app can use it without help

## The repo

- [ ] The repo is **public** (the open-source challenges need this). The repo owner can switch
      it in Settings, under "Danger Zone", "Change visibility"
- [ ] `README.md` follows `docs/README-template.md`, with every [bracket] filled in
- [ ] The README names the model (`gemma-4-26b-a4b-it`) and links its Apache 2.0 licence
- [ ] The README credits every dataset the app uses, with the credit line from `data/README.md`
- [ ] The README lists the AI tools we used and what each did
- [ ] `LICENSE` is MIT
- [ ] `.env` is not on GitHub, and no API key appears in any file
- [ ] Snowflake challenge only: the "How CoCo helped" section is filled in, with account names
      removed

## The pitch

- [ ] The final slide credits every dataset
- [ ] We can say who the app helps in one sentence
- [ ] The demo has been run end to end at least once, on the laptop we will present from
